# Abstract {#sec:abstract-en}

Intrusion detection in Internet of Things networks needs models that are accurate and fit the limited resources of IoT devices. This seminar reviews the paper by Abdulkareem et al. (2024), which reduces the feature space with ExtraTrees feature importance (FI) and classifies traffic with a stacking ensemble (SEL). The ensemble uses Naive Bayes and logistic regression as base learners and a decision tree as the meta-learner. A support paper that compares five dimensionality reduction methods and finds permutation feature importance (PFI) the best is used for comparison. We reimplemented the method on the Edge-IIoTset dataset with six classes and five random seeds, and compared FI with PFI, mutual information and PCA. The leakage-free reimplementation reached a macro-F1 of 82.57 with all features and 81.59 with eight features, within one point of the paper. PFI with eight features reached 82.25 and trained faster. The review shows that the claimed 86.9% storage reduction is a ratio of feature counts, and the measured pipeline size did not shrink. Algorithm 1 of the paper suggests possible data leakage, but a literal implementation of it reaches a macro-F1 of about 90 and does not reproduce the reported results. The weak recall of the MITM class comes from an all-zero feature vector shared by several classes, and class weighting does not fix it. Removing duplicate rows raised macro-F1 to about 92. A single decision tree was as accurate as the SEL.

Keywords: intrusion detection, Internet of Things, feature selection, permutation feature importance, stacking ensemble, Edge-IIoTset, reimplementation
